# Counter-Blockchain (MVP)

Прототип браузерного FPS (first-person) без регистрации:

- лёгкий рендер (raycasting, ретро-стиль как у старых шутеров),
- базовая физика столкновений,
- стрельба, урон, перезарядка,
- боты с простым AI,
- матч на время и очки,
- заглушка «личного кабинета» с локальным обменом очков на CBT.

## Запуск

Открой `index.html` в браузере.

Для корректной работы `Pointer Lock` лучше запускать через простой локальный сервер, например:

```bash
python3 -m http.server 8080
```

После этого открой `http://localhost:8080`.

## Управление

- `WASD` — движение
- мышь — обзор
- ЛКМ — стрельба
- `Shift` — бег
- `R` — перезарядка

## Важное

Криптообмен в этой версии — только симуляция в `localStorage`.
